 ## Features

 - Clean, responsive layout built with Tailwind CSS

 ## Tech stack

 - React (JSX)

 - Tailwind CSS for styling

 ## Project structure

 - `src/` — React source files (App, data, assets)
 - `public/` — Static assets (images, videos)
 - `index.html` — App entry point
 - `package.json` — Scripts and dependencies

 ## Local development

 Requirements:
 - Node.js 16+ (recommended 18+)

 Install dependencies:

 ```bash
 npm install
 ```

 Run dev server:

 ```bash
 npm run dev
 ```

 Build for production:

 ```bash
 npm run build
 npm run preview
 ```

 ## How the projects data works

 Project cards are rendered from `src/data.js`. Each project entry uses the shape:

 ```js
 { title: "Project Name", description: "Short description", tags: ["React", "JS"], repoUrl: "https://github.com/owner/repo" }
 ```

 Edit `src/data.js` to add, remove, or update project entries.
